# SubsNet Releases

   Public mirror for installer downloads and the auto-update feed.
   Source code and development happens in the private `subsnet/subsnet` repo.

   Latest release files (`.exe`, `.dmg`, `latest.yml`, `.blockmap`) are
   automatically published here by `electron-builder` from CI/local build.

   Users do not need to download from this repo manually — the SubsNet app
   itself checks `latest.yml` here on launch and auto-downloads updates.
